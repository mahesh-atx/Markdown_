# Markdown_ 

Custom Markdown Renderer — MD Reader.

- Open a folder (shows subfolders + only .md files)
- Load a public GitHub repo (.md tree)
- Upload .md files (modal with drag & drop)
- Document tabs bar (keep multiple files open side-by-side)
- GitHub-style callout alerts (`[!NOTE]`, `[!TIP]`, `[!WARNING]`, `[!IMPORTANT]`, `[!CAUTION]`)
- Mermaid.js diagram rendering (````mermaid` blocks)
- LaTeX math formulas via KaTeX (inline `$E=mc^2$` and block `$$...$$`)
- Compact, proper sidebar with desktop toggle (`Ctrl+B`)
- File search & workspace switcher, persisted via IndexedDB

Run via file:// or any static server — no build step required.
